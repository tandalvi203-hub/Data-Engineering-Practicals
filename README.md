# Data Engineering Practicals

This repository contains the practical implementations and mini project completed for the Data Engineering course.

## Practicals

| Practical | Topic |
|---|---|
| Practical 1 | Data Handling, File Processing, Regular Expressions & SQL CRUD |
| Practical 2 | ETL Process using Power BI |
| Practical 3 | MongoDB Document Insertion and Retrieval |
| Practical 4 | Data Cleaning, Feature Selection & EDA using Python |
| Practical 5 | REST API and CSV Data Extraction, Transformation & Merging |
| Practical 6 | ETL Pipeline Orchestration using Apache Airflow |
| Practical 7 | Python-based ETL Pipeline |
| Practical 8 | PySpark DataFrame Operations |
| Practical 9 | End-to-End E-Commerce ETL Pipeline |
| Practical 10 | Data Engineering Mini Project – Power BI Dashboard |

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Power BI
- MongoDB
- SQLite
- Apache Airflow
- PySpark
- SQL
- REST API

## Overview

These practicals demonstrate key Data Engineering concepts including data extraction, transformation, cleaning, validation, database operations, ETL pipelines, workflow orchestration, distributed data processing, and data visualization through Power BI.
